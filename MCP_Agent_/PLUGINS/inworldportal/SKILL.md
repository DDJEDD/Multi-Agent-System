# Инструкция по использованию плагина Inworld TTS (ReqTTSAudio)

Плагин `inworld` предоставляет возможность синтеза речи (Text-to-Speech) с использованием сервиса Inworld AI. Сгенерированные аудиофайлы сохраняются на сервере в формате MP3.

## Функция: `ReqTTSAudio`

Используйте эту функцию, когда вам необходимо озвучить текст и получить файл озвучки.

### Параметры вызова:
- **`text`** (string, обязательный): Текст, который необходимо озвучить.
- **`voiceId`** (string, опционально): Идентификатор голоса. По умолчанию: `"Ashley"`. Доступные голоса: `"Ashley"`, `"Alex"`, `"Dennis"`, `"Phoebe"` и др.
- **`modelId`** (string, опционально): Идентификатор модели синтеза. По умолчанию: `"inworld-tts-2"`.
- **`audioEncoding`** (string, опционально): Формат кодирования аудио. По умолчанию: `"MP3"`.
- **`fileName`** (string, опционально): Имя создаваемого файла (без расширения или с `.mp3`). По умолчанию: `"output_audio"`.

### Пример вызова функции:
```json
{
  "functionName": "ReqTTSAudio",
  "args": {
    "text": "Привет! Я сгенерировал эту озвучку с помощью Inworld.",
    "voiceId": "Ashley",
    "fileName": "greeting_message"
  }
}
```
