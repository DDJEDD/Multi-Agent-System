# Инструкция по использованию плагина ffmpeg (renderVideo)

Плагин собирает готовый ролик из уже сгенерированных клипов, озвучки и музыки: склеивает клипы с переходами, ставит озвучку по блокам, подмешивает музыку (она тише под голосом), накладывает субтитры и экранные надписи. Результат сохраняется в mp4, в ответе приходит путь.

Вызывайте функцию один раз, когда все файлы уже готовы (клипы из generateVideo, озвучка). Рендер занимает от десятков секунд до пары минут. Если одновременно идёт другой рендер, вызов встанет в очередь и вернёт ответ, когда до него дойдёт очередь. Не повторяйте вызов.

## Функция: `renderVideo`

### Параметры
- **`project`** (object, обязательный): описание ролика, см. ниже.

### Поля project
- **`output`** (string): имя файла, например `"vickers.mp4"`. Если такое уже есть, добавится суффикс.
- **`size`** (string): `"720x1280"` по умолчанию. **`fps`** (number): 30 по умолчанию.
- **`clips`** (array, обязательный): список клипов по порядку. Элемент: путь строкой или объект `{"file": путь, "trim": секунды, "start": секунды, "transition": {...}}`. `trim` обрезает клип до указанной длины. `transition` в элементе задаёт переход ИЗ предыдущего клипа В этот.
- **`transition`** (object): переход по умолчанию для всех стыков, `{"type": "fade", "duration": 0.3}`. Типы: fade, fadeblack, fadewhite, dissolve, slideleft, slideright, slideup, slidedown, wipeleft, wiperight, wipeup, wipedown, smoothleft, smoothright, circleopen, circleclose, radial, zoomin, pixelize, hblur. `"none"` или `"cut"` даёт жёсткий стык.
- **`voice`** (array): озвучка. Если это список путей, i-й файл ложится на начало i-го клипа. Объект: `{"file": путь, "block": 2, "offset": 0.1, "volume": 1}`.
- **`voice_offset`** (number): общий сдвиг озвучки относительно начала блока, секунды (по умолчанию 0).
- **`music`** (object): `{"file": путь, "volume": 0.2, "duck": true, "fade_out": 1.5}`. `duck` приглушает музыку, пока звучит голос. Музыка зацикливается и обрезается по длине ролика.
- **`clip_audio`** (number): громкость собственного звука клипов, 0 = выключен (по умолчанию).
- **`subtitles`** (array): `{"block": 1, "text": "..."}` ставится по времени озвучки этого блока; можно задать абсолютно `{"start": 1.0, "end": 3.5, "text": "..."}`. Текст автоматически режется на короткие порции по 3 слова.
- **`accents`** (array): экранные акценты `{"block": 1, "start": 0.2, "end": 2.5, "text": "12 ЧАСОВ"}`. При `block` время start/end считается от начала блока.
- **`fit`** (string или object): авто-подгонка длины клипов и озвучки друг под друга, по умолчанию выключена. Режимы: `"auto"` (подгоняются и видео, и озвучка), `"video"` (меняется только клип: обрезается, чуть замедляется, а недостающее добивается заморозкой последнего кадра), `"voice"` (меняется только озвучка: ускоряется или замедляется в пределах 0.9–1.15). Параметры в объекте: `{"mode": "auto", "pad": 0.4, "max_audio_speed": 1.15, "min_audio_speed": 0.9, "min_video_speed": 0.85}`. `pad` — запас после озвучки в блоке, секунды. Подгонка работает для озвучки, привязанной к блоку (список путей или `block`). После подгонки в ответе будет строка «Подгонка: ...», перескажите её пользователю коротко.
- **`style`** (object): `{"font": "...", "sub_size": 51, "accent_size": 83, "sub_color": "FFFFFF", "accent_color": "FFD400"}`.

Блоки нумеруются с 1 и совпадают с номерами клипов. Из-за переходов общий ролик короче суммы клипов на длительность стыков (например, 6 клипов по 6 сек с переходами 0,3 сек дают 34,5 сек), плагин сам считает, где начинается каждый блок.

### Пример вызова
```json
{
  "functionName": "renderVideo",
  "args": {
    "project": {
      "output": "vickers.mp4",
      "transition": {"type": "fade", "duration": 0.3},
      "clips": ["C:/out/1.mp4", "C:/out/2.mp4", "C:/out/3.mp4", "C:/out/4.mp4", "C:/out/5.mp4"],
      "fit": "auto",
      "voice": ["C:/tts/b1.wav", "C:/tts/b2.wav", "C:/tts/b3.wav", "C:/tts/b4.wav", "C:/tts/b5.wav"],
      "music": {"file": "C:/music/dark.mp3", "volume": 0.2},
      "subtitles": [{"block": 1, "text": "Двенадцать часов огня без остановки. Стволы перегревались."}],
      "accents": [{"block": 1, "start": 0.2, "end": 2.5, "text": "12 ЧАСОВ"}]
    }
  }
}
```

## Ответ плагина
- Успех: `Готово, файл: <путь> (<длительность> с)`. Если есть «Внимание: ...», например озвучка длиннее блока, сообщите об этом пользователю.
- Ошибка: текст причины (файл не найден, неизвестный переход, ffmpeg не найден). Объясните суть простыми словами, технические детали не пересказывайте.
