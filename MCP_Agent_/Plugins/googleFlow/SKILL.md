# Инструкция по использованию плагина Google Flow (generateImage, generateVideo)

Плагин генерирует картинки и видео через Google Flow (Imagen / Nano Banana и Veo). Результат сохраняется на сервере в файл, в ответе приходит путь к нему. Генерация занимает от десятков секунд до нескольких минут, поэтому вызывайте функцию один раз и дождитесь результата. Не запускайте несколько генераций одновременно.

## Функция: `generateImage`

Используйте, когда нужно создать картинку по описанию.

### Параметры вызова:
- **`prompt`** (string, обязательный): Описание картинки. Чем конкретнее (объект, стиль, свет, композиция), тем лучше результат.
- **`aspect`** (string, опционально): Соотношение сторон: `"16:9"`, `"9:16"`, `"1:1"`. По умолчанию `"16:9"`.
- **`model`** (string, опционально): Идентификатор модели. Указывайте, только если пользователь назвал модель. Допустимые значения: <ЗАПОЛНИТЬ из `gflow image t2i --help`>.
- **`count`** (number, опционально): Сколько картинок сгенерировать за один вызов. По умолчанию 1, максимум 4.

### Пример вызова функции:
```json
{
  "functionName": "generateImage",
  "args": {
    "prompt": "Рыжий кот в скафандре на поверхности Луны, кинематографичный свет",
    "aspect": "9:16"
  }
}
```

## Функция: `generateVideo`

Используйте, только когда пользователь явно просит именно видео. Каждая генерация тратит кредиты аккаунта и занимает несколько минут: не вызывайте её «на пробу» и не повторяйте при неудаче без запроса пользователя. Если в ответе написано, что генерация видео отключена, или что видео уже запускали недавно, просто сообщите об этом пользователю.

### Параметры вызова:
- **`prompt`** (string, обязательный): Описание сцены: что происходит, как движется камера, настроение.
- **`aspect`** (string, опционально): Соотношение сторон, например `"16:9"` или `"9:16"`.
- **`duration`** (number, опционально): Длительность ролика в секундах. Если не указана, используется значение по умолчанию. Слишком большое значение будет автоматически уменьшено до лимита. Допустимые значения: <ЗАПОЛНИТЬ из `gflow video t2v --help`>.
- **`model`** (string, опционально): Идентификатор модели. Указывайте, только если пользователь назвал модель. Допустимые значения: <ЗАПОЛНИТЬ из `gflow video t2v --help`>.
- **`count`** (number, опционально): Сколько роликов сгенерировать. По умолчанию 1, обычно разрешён только 1.

### Пример вызова функции:
```json
{
  "functionName": "generateVideo",
  "args": {
    "prompt": "Медленный пролёт камеры над утренним туманным лесом",
    "aspect": "16:9",
    "duration": 6
  }
}
```

## Ответ плагина
- Успех: `Готово, файл: <путь>`. Если файлов несколько, пути разделены `;`.
- В конце может быть пометка «пропущены неподдерживаемые параметры»: это значит, что часть настроек (например, длительность) не применилась и ролик сделан с настройками по умолчанию. Сообщите об этом пользователю.
- Ошибка: текст причины (нужен вход в аккаунт, не уложились во время, видео отключено, gflow занят). Объясните суть простыми словами, технические детали не пересказывайте.
- Если сказано, что ролик создан, но не скачался, не генерируйте его заново: передайте пользователю команду для ручного скачивания.
